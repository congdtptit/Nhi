# Bài tập Wayground

Trang web tĩnh, mở trong trình duyệt. Được dựng bằng scripts/build_quiz.py --offline.

- `index.html` — bộ đề cũ (dữ liệu trong `quiz-project/`)
- `thang-10.html` — Phiếu tháng 10 (dữ liệu riêng trong `quiz-thang-10/`)
- `thang-11.html` — Phiếu tháng 11 (dữ liệu riêng trong `quiz-thang-11/`)
